A static site for testing audits

This site exists so that an audit has something to find. Each page has a known set of problems, and the audit is expected to report exactly those and to name the file and the line each one comes from.

The home page itself is in good shape: it has a title of its own, a meta description, one main heading and enough text to count as real content for the checks that look at the amount of text on a page.
